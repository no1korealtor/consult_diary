========== [ 대표님 전용 봇 수동 실행 명령어 ] ==========

* 실행 방법: 
'작업실열기.bat'를 더블클릭해서 까만 창(cmd)을 띄운 뒤, 
아래 명령어를 입력하고 엔터(Enter)를 치세요!

★ [추천/기본] 통합 런처(메뉴판) 실행
명령어: python autobot_launcher.py
(메뉴 화면에서 1, 2, 3, 4, 5번 작업을 자유롭게 선택하여 실행할 수 있습니다)

--------------------------------------------------------
[개별 바로 실행하고 싶을 때 (단축 명령어)]

1. 부동산써브 매물 등록 봇 개별 실행
명령어: python serve_auto_upload.py

2. LH 전세임대포털 매물 등록 봇 개별 실행
명령어: python lh_auto_upload.py

3. 부동산써브 매물 대량 검증 봇 개별 실행
명령어: python audit_serve_list.py

4. 실거래가 조회 및 비교 개별 실행 (자동 유형 판별 적용)
명령어: python trade_viewer.py

5. 건축물대장 간편 열람 개별 실행 (호수별 구성표 조회)
명령어: python building_viewer.py

6. [신규] 부동산 정보 조회기 통합 런처 개별 실행
명령어: python info_viewer_launcher.py

※ 나머지 프로그램 실행 후 동작은 모두 기존과 똑같습니다!
