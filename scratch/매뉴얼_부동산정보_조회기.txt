┌─────────────────────────────────────────────────────────────┐
│  부동산 정보 간편 조회기 (건축물대장 + 실거래가) 사용설명서   │
└─────────────────────────────────────────────────────────────┘

본 프로그램은 로그인이나 브라우저 조작 없이 주소 입력만으로
전국 모든 건물의 건축물대장 요약 정보와 최근 1년 실거래 정보(매매/전월세)를
한 번에 통합하여 조회하고 자동으로 비교 분석할 수 있는 업무 지원 도구입니다.

===============================================================
  1.  시작하기 및 프로그램 실행
===============================================================
  - 배포된 압축 파일을 해제하고, 폴더 내의 「부동산정보_조회기.exe」를
    더블클릭하여 실행합니다.
  - 실행 즉시 1개월 무료 체험 기간이 활성화되며, 검은색 화면(콘솔)에
    주소 입력창이 나타납니다.

===============================================================
  2.  주요 기능 사용법 (단일 통합 조회)
===============================================================
  - 프로그램 실행 시 번거로운 메뉴 선택창 없이, 바로 주소 입력창이 뜹니다.
  - 고객 상담 중 주소를 말하면 바로 입력하여 대장과 실거래가를 한 화면에 출력합니다.

  [입력 예시]
  - 집합건물(다세대, 아파트, 오피스텔 등): "성산동 138 402호" 처럼 동/호수까지 상세히 입력합니다.
  - 일반건물(단독, 다가구, 상가 등): "성산동 138" 또는 "창전동 12" 처럼 지번까지만 입력합니다.

  [조회 및 출력 정보]
  - 대지/건축/연면적, 건물 구조, 주용도, 승인일, 층수, 세대수, 주차대수, 위반 여부를 한 번에 출력합니다.
  - 공동주택(집합건축물)이고 동/호수를 지정하여 입력한 경우:
    * 해당 호수의 개별 전유부 상세 스펙(해당층, 전용면적, 공급면적, 대지지분비율, 호수별 위반 여부)이 함께 조회됩니다.
  - 공동주택이지만 동/호수를 지정하지 않은 경우:
    * 전체 세대의 층별 호수 구성 리스트가 출력되어 공실 및 호실 배치를 바로 파악할 수 있습니다.
  - 일반건축물(다가구 등)인 경우:
    * 공유지분이 있을 경우 토지대장에 등록된 지분 소유 정보 목록을 찾아 출력합니다.
  - 실거래가 자동 비교 (최근 5건):
    * 해당 지번의 최근 실거래 내역(매매/전세/월세 불문) 중 최신 5건을 가져와 표로 보여줍니다.
    * 만약 특정 호실(예: 402호)을 조회했다면, 그 호실의 층수와 전용면적을 기준으로 실거래 사례들의 층 차이와 면적 차이를 자동으로 계산해 비교 테이블에 띄워줍니다. (층수/면적 수기 입력 단계 생략)
    * 특정 호실을 입력하지 않은 경우, 실거래 내역 중 가장 최신 거래를 기준으로 나머지 거래들을 자동 비교합니다.

===============================================================
  3.  오류 해결 및 필수 요청 사항 (403 에러 발생 시)
===============================================================
  - 아파트 외에 빌라(연립다세대), 오피스텔 조회가 안 되고 403 Forbidden 에러가
    발생하는 경우, 이는 국토부 API 권한 승인이 필요하기 때문입니다.
  - 공공데이터포털(data.go.kr)에 로그인하신 뒤, 마이페이지 혹은 검색창에서 
    아래 API들을 검색하여 [활용신청]을 눌러주시기 바랍니다. (즉시 자동 승인)
    * 국토교통부 연립다세대 전월세 실거래가 자료 / 연립다세대 매매 실거래가 자료
    * 국토교통부 아파트 전월세 실거래가 자료 / 아파트 매매 실거래가 상세 자료
    * 국토교통부 오피스텔 전월세 자료 / 오피스텔 매매 실거래가 자료
    * 국토교통부 단독/다가구 전월세 자료 / 단독/다가구 매매 실거래가 자료
    * 국토교통부 건축물대장정보 서비스

===============================================================
  4.  법적 고지 및 면책 사항
===============================================================
  - 본 프로그램이 제공하는 데이터는 정부 오픈 API에 실시간 등록된 정보를
    바탕으로 합니다. 단, 정부 API 자체의 전산 지연이나 데이터 누락(위반건축물 표기 오류 등)이
    있을 수 있습니다.
  - 따라서 계약서 작성이나 중요 브리핑 시에는 반드시 정부24에서 공식 공부를 
    직접 발급받아 교차 확인하셔야 하며, 프로그램 사용으로 인한 불이익이나 
    사고에 대해서는 일체의 법적 책임을 지지 않습니다.
